ENGINE NOTESHELP AND REFERENCES

Scores compare hardware fit; they are not measured success probabilities. Each engine has separate Big Brick and Mini Brick checks. The developer has run VQ35DE and a Gen IV LS engine successfully on Big Brick (exact LS code not yet recorded).

Hardware notes: Standard high-impedance port injectors work natively. Factory GDI requires specialized control (not validated on Big Brick and unavailable on Mini); some unusual factory triggers need alternative hardware.
How confidence scores work

Seven separate layers: crank trigger (25 points), injector outputs (15), ignition signal count (14), coil and igniter type (14), cam/VVT control (14), factory MAP/MAF load sensing (8), and port injection versus GDI (10). Each layer shows its evidence, uncertainties and remaining work. The overall total is capped at 79/100 without a validated installation.

MAP versus MAF: A correctly calibrated manifold MAP sensor is preferred for speed-density tuning, but MAF remains an option. A charge-pipe pressure sensor is not automatically suitable as a full-range manifold MAP sensor. Read rusEFI's load-sensing guidance.

Ignition: sourced smart coils score highest. External ignition power stages are assessed separately; Mini Brick has no independently verified high-current dumb-coil drivers. Distributor systems can use one ignition signal with a suitable igniter, but locked base timing and rotor alignment require verification.

What does 0/100 mean? The original engine configuration has a native blocker, such as unsupported GDI, an unsupported stock optical trigger or unsuitable hardware capacity. It does not rule out a future, independently validated modification.

Research classifications: a named rusEFI decoder does not prove OEM wheel compatibility; a candidate wheel does not guarantee cam sync; and verified sources do not establish an installed Brick ECU harness or calibration.

Catalog status: Engine-specific reference links are available in each entry; they are not downloadable tunes or universal wiring diagrams.
