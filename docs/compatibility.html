READ BEFORE USING A PRESETRESEARCH STATUS

Confidence percentages are engineering screening scores, not measured probabilities that an engine will start, run reliably, or work without modifications. Every preset has an independent Big Brick and Mini Brick estimate. They assume the listed stock trigger, factory fuel type, and that no vehicle-specific ECU installation has been verified.

Scoring rules: Named firmware decoder: 42 evidence points; plausible physical-wheel match: 30; decoder unverified: 14. Documented cam/phase information adds 3–12 points. Basic output capacity adds up to 26 points for Big Brick and 24 for Mini Brick. Scores are then reduced or capped for six-cylinder Mini installations, 9–12-cylinder batch injection, unsupported original optical triggers, high-current Valvetronic motors, complex quad-VVT, problematic decoders and reported Honda K timing wander. Scores cannot exceed 80% without actual Brick ECU validation.

0% means the stock factory configuration has a known native incompatibility or is outside the modeled hardware scope—not that aftermarket engine modifications, external controllers or future software can never make it work. Factory GDI, unsupported Nissan optical CAS and firmware-marked broken decoders score 0% on the original hardware.

Named decoder: Current rusEFI firmware lists the pattern by name; no Brick ECU installation is implied. Wheel-pattern candidate: A physical wheel may match a generic decoder; sync and polarity still need checking. Needs verification: No complete crank/cam configuration has been established. Stock trigger unsupported: The current configuration is not a viable native decoder match.

Brick ECU constraints: Up to 300 teeth per crank revolution; Big Brick up to 8-cylinder sequential fuel/spark or up to 12-cylinder batch fuel/sequential spark. Native direct injection is not validated, and external GDI control has not been tested. The Honda K 12+1 decoder has an unverified community-reported timing-wander concern.

Sixteen original entries remain decoder-only without independently established production-year OEM wheel details; 46 contain explicit regular missing-tooth crank candidates. Family-level and partial evidence are labeled and are not a proven Brick ECU installation. These are not downloadable base tunes, validated pin maps or install approvals.
