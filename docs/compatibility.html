READ BEFORE USING A PRESETRESEARCH STATUS

Confidence percentages are engineering screening scores, not measured probabilities that an engine will start, run reliably, or work without modifications. Every preset has a separate Big Brick and Mini Brick score for each layer. They assume the listed stock trigger, factory fuel type, and that no vehicle-specific ECU installation has been verified.

Seven independent layers, each shown for Big and Mini: (1) crank trigger/decoder 25 points, (2) injector count and available outputs 15, (3) coil count and ignition signals 14, (4) coil type and ignition power stage 14, (5) cam sync, VVT wheel and VR channels 14, (6) factory MAP/MAF and tunability 8, and (7) port-injection versus factory GDI 10. Open any layer to read the evidence, unresolved work and source links. Current total capped at 79 without a validated Brick installation. Read full scoring methodology and source-policy details.

MAP preference: rusEFI speed-density is favored where a suitable calibrated manifold MAP sensor exists. MAF is a supported alternative, not inherently incompatible; installing an external 0–5 V manifold MAP may be needed. Do not mistake a charge-pipe boost sensor for a manifold MAP sensor. rusEFI load-control reference.

Ignition hierarchy: sourced smart coils rank highest, external power-stage coils are conditional, Big Brick has six IGBT channels for passive coils (within the same sixteen low-side channels), and Mini Brick has no separately verified high-current coil drivers. A distributor/single coil with igniter can be controlled with one ignition signal, but baseline timing and rotor phasing require careful verification on adjustable distributors. Unknown coil type is not treated as smart or dumb.

0/100 means the stock factory configuration has a known native incompatibility or is outside the modeled hardware scope—not that aftermarket engine modifications, external controllers or future software can never make it work. Factory GDI, unsupported Nissan optical CAS and firmware-marked broken decoders score 0% on the original hardware.

Named decoder: Current rusEFI firmware lists the pattern by name; no Brick ECU installation is implied. Wheel-pattern candidate: A physical wheel may match a generic decoder; sync and polarity still need checking. Needs verification: No complete crank/cam configuration has been established. Stock trigger unsupported: The current configuration is not a viable native decoder match.

Brick ECU constraints: Up to 300 teeth per crank revolution; Big Brick up to 8-cylinder sequential fuel/spark or up to 12-cylinder batch fuel/sequential spark. Native direct injection is not validated, and external GDI control has not been tested. The Honda K 12+1 decoder has an unverified community-reported timing-wander concern.
