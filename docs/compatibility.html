READ BEFORE USING A PRESETRESEARCH STATUS

Named decoder: Current rusEFI firmware lists a decoder by name; no Brick ECU installation is implied. Wheel-pattern candidate: A physical wheel may match a generic decoder; sync and polarity still need checking. Needs verification: No complete crank/cam configuration has been established. Not recommended: Upstream decoder has a known warning.

Brick ECU constraints: Up to 300 teeth per crank revolution; Big Brick up to 8-cylinder sequential fuel/spark or up to 12-cylinder batch fuel/sequential spark. Native direct injection is not validated, and external GDI control has not been tested. The Honda K 12+1 decoder has an unverified community-reported timing-wander concern.
