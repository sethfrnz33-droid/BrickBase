Wiring examples

New to Big Brick? Follow the illustrated engine setup guide.

Seven clear wiring references for common sensors and outputs. The numbered pins shown are examples, not compulsory assignments: a suitable unused channel of the same electrical type can be configured instead (for example, D1, D4 or D5 for a compatible Hall sensor). Keep each signal on its own assigned pin, use the pinout lookup to confirm function and ratings, and do not interchange different signal types. Select any diagram to view the full-size image.
