Software / Communications

Wi-Fi tuning and network communication

Big Brick includes an onboard ESP32 connected to the ECU through CAN and USB. Brick ECU has developed software for network-based communications and wireless tuning.

Onboard network hardware

ESP32, ECU CAN link and USB communication.

Engine interfaces

Two CAN buses and two onboard wideband controllers.

Confirm the software build and ECU hardware revision before flashing. Previous 94-pin board mappings are not compatible wiring instructions for this release.
